# Security policy

CyberShield is a student hackathon project and a work in progress. It is not meant for production use.

## Reporting a problem

If you find a security problem in this code (for example, a way to bypass analyst approval, inject commands, or forge audit-log entries), please report it **privately** through this repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue for it.

Please include what you found, how to reproduce it, and what an attacker could do with it. We'll acknowledge reports as soon as we can during the hackathon.

## Scope

- In scope: the code in this repository (`orchestrator/`, `wazuh/`).
- Out of scope: Wazuh, Suricata and Cowrie themselves. Report those to their own projects.

## Responsible use

Only run the attack scripts and test traffic against systems you own or are explicitly authorised to test.
